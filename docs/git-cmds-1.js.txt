// Commands to Diagnose Sync Issues

git status
git remote -v
git fetch --all --prune
git branch -vv
git log --oneline --graph --decorate --all
git diff
git diff origin/<branch>
git show-branch --more=20

// </branch> Commands to Handle Local Changes Before Syncing

git add <files>
git commit -m "<message>"
git stash push -m "<reason>"
git stash list
git stash pop
git stash apply
git stash drop
git stash clear


// Commands to Pull Remote Updates Cleanly
git pull --no-rebase
git pull --rebase origin <branch>
git pull origin <branch>
git rebase origin/<branch>
git merge origin/<branch>
git reset --hard origin/<branch> (discard local changes)


// Commands for Conflict Resolution

q (identify conflicted files)
Edit files to resolve conflicts
git add <resolved-file>
git rebase --continue
git merge --continue
git rebase --abort
git merge --abort
git checkout --ours <file>
git checkout --theirs <file>
git diff --name-only --diff-filter=U


// Commands to Reconcile Diverged Histories

git log origin/refactor-2025-08-25..HEAD --oneline
git push origin <branch>
git push --force-with-lease origin <branch>
git cherry-pick <commit>
git reflog
git revert <commit>
git reset --hard <commit>
git clean -fd


// Commands to Verify Sync Completion

git status
git log origin/<branch>..HEAD
git log HEAD..origin/<branch>
git push origin <branch>
git fetch --all --prune
git branch -vv

# List local branches:
git branch

# List remote branches:
git branch -r

# List all branches (local + remote):
git branch -a

# List branches with last commit info:
git branch -vv

# Bonus – list only merged branches:
git branch --merged


And to list unmerged ones:

git branch --no-merged


Syncing Local and Remote Git Branches
1. Verify your working tree

git status

Ensure you’re on the right branch and have no uncommitted changes you don’t want to rebase.

2. Fetch remote updates
git fetch origin refactor-2025-08-25
3. Switch to (or confirm you’re on) the branch
git switch refactor-2025-08-25
4. Rebase local work on top of the remote branch
git pull --rebase origin refactor-2025-08-25
If conflicts occur: fix them, then run

git add <files>
git rebase --continue
5. Push local commits back to the remote
git push origin refactor-2025-08-25
If you rewrote history during the rebase and must overwrite the remote branch:

git push --force-with-lease origin refactor-2025-08-25
6. Optional cleanup
git fetch --prune
